About EBA DPM Table Layouts

This application renders EBA DPM Reporting Table Layouts directly in the browser using static Parquet files and DuckDB-Wasm.

  • Zero Backend: Runs 100% in browser memory via WebAssembly.
  • Multi-Level Headers: Hierarchical X column trees and Y row groups.
  • XBRL-CSV Report Loader: Import `.csv` / `.zip` report files to map reported values (`dp{VariableID}`) directly into layout cells.
