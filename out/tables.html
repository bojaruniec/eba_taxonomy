About EBA DPM Table Layouts

This is a 100% static, serverless DPM Table Layout Viewer for EBA Reporting Frameworks (Pillar 3 / CODIS).

Content Lineage & Source:

  • Source File: DPM2 Database_v 4_3_20260622.accdb
  • Framework Version: EBA Reporting Framework 4.3 & 4.2
  • Source Link: Download ZIP

Datapoint Identification:

Each cell is identified by its XBRL-CSV datapoint code dp{VariableID} and DPM VariableVID, enabling 1:1 mapping with Pillar 3 Data Hub XBRL-CSV reports.
